# Entrega do Backend

Esta pasta organiza a implementação do backend em duas etapas:

```text
backend/
├── MVP/
│   ├── specs/
│   └── prompts/
└── features-completas/
```

## MVP

Contém somente as especificações e os prompts necessários para entregar o primeiro backend utilizável da Esteira Habitacional.

O MVP deve resolver o problema central do produto:

- centralizar processos de financiamento;
- controlar participantes e acessos;
- organizar etapas e próxima ação;
- solicitar, receber, versionar e analisar documentos;
- controlar pendências;
- manter histórico rastreável;
- oferecer consultas adequadas para analista, corretor e cliente.

A ordem dos arquivos é obrigatória. Cada prompt implementa a especificação de mesmo número e pressupõe que os anteriores estejam concluídos.

## Features completas

A pasta `features-completas/` permanece vazia nesta fase. Ela será usada somente após:

1. backend MVP concluído e estabilizado;
2. frontend MVP criado;
3. integração frontend-backend validada;
4. aprendizado obtido com uso ou validação de clientes.

Não antecipar funcionalidades futuras dentro do MVP.
