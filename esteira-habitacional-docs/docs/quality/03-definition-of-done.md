# Definition of Done

Uma funcionalidade só é considerada concluída quando:

- atende aos critérios de aceite;
- respeita limites arquiteturais;
- possui testes adequados;
- não introduz regra de negócio no controller ou infraestrutura;
- aplica autorização backend;
- possui tratamento de erros;
- registra auditoria quando necessário;
- possui estados de UI de loading, erro e vazio;
- é responsiva quando aplicável;
- passa build, testes e análise estática;
- possui migration quando altera dados;
- atualiza documentação e contrato de API;
- não expõe dados sensíveis em logs;
- foi revisada por outra pessoa ou agente;
- não deixa código morto ou TODO sem rastreamento.
